Environment Banner

A clear warning banner for staging and non-production databases.

The default banner, shown automatically on a staging database.

Overview

Working on a staging or test database that looks exactly like production is a recipe for mistakes: test e-mails sent to real customers, dummy records created on live data, or hours lost to confusion between environments. Environment Banner paints a colored, always-visible bar above the navigation bar so every user immediately knows they are not working on production.

Key Features

  • Automatic detection — the banner appears on neutralized databases and on databases whose name contains staging, test or demo.
  • Manual override — force the banner on or off with one system parameter, whatever the automatic detection says.
  • Custom text and color — adapt the message and background color to your workflow (e.g. different colors per client or per stage).
  • Zero footprint — pure server-side QWeb. No JavaScript, no bundled assets, no dependency beyond the standard web module.
  • Proven rendering — the technique works identically from Odoo 14 to Odoo 19, so you can standardize all your environments on one module.

How It Works

The module extends the web client bootstrap template. On every page load, before the page is rendered, it checks the database and the configuration parameters, and when the environment is not production it renders the warning bar above the navbar. There is nothing to configure on install: it works out of the box on databases it can detect, and stays completely invisible everywhere else.

Configuration

All options are standard system parameters (Settings > Technical > System Parameters):

Parameter Default Description
environment_banner.mode auto auto, on (always show) or off (never show)
environment_banner.label built-in message Custom banner text
environment_banner.color #D0442C Banner background color (CSS color)

Example: set environment_banner.mode to on and environment_banner.color to #7A4DD7 to mark an internal training database with a purple banner.

Fully customizable: your own text, your own color.

The banner follows users into every application — impossible to miss.

Technical Notes

  • The bar is rendered server-side on every page — no client-side flicker.
  • No data is collected, no external calls are made, nothing is downloaded.
